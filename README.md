# Hotel Booking Demand — Exploratory Data Analysis

## Project Overview

This project explores hotel reservation data using Python and data analysis libraries. The objective is to identify booking patterns, understand cancellation behaviour, investigate hotel pricing, and discover meaningful insights.

## Dataset

**Source:** [Hotel Booking Demand — Kaggle](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)

The dataset contains reservation information for City Hotels and Resort Hotels.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Dataset structural analysis
- Missing value analysis
- Duplicate record identification
- Descriptive statistics
- Categorical variable analysis
- Distribution analysis
- Correlation analysis
- Cancellation behaviour analysis
- Monthly booking trends
- Hotel pricing analysis
